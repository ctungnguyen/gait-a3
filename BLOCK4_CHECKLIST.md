# Part II Block 4 — final control-set checklist

## Style 1: rotation, movement, and thrust

- [x] Uses its own `Discrete(5)` action space
- [x] Action `0` performs no input
- [x] Action `1` applies thrust only in the ship's current forward direction
- [x] Action `2` rotates left without direct translation
- [x] Action `3` rotates right without direct translation
- [x] Action `4` shoots in the current forward direction
- [x] Heading is bounded during long training runs for numerical stability
- [x] Manual controls: W/Up thrust, A/D or Left/Right rotate, Space shoot
- [x] Dedicated visual evaluator: `evaluate_rotation.py`
- [x] Dedicated model path: `models/rotation_agent.zip`

## Style 2: direct directional movement

- [x] Uses its own `Discrete(6)` action space
- [x] Action `0` performs no input
- [x] Actions `1–4` move Up, Down, Left, and Right on world axes
- [x] Action `5` shoots in the last movement/facing direction
- [x] Direct movement is semi-continuous, accelerated, speed-limited, and
  independent of the rotation/thrust rules
- [x] Manual controls: WASD/arrows move, Space shoots
- [x] Dedicated visual evaluator: `evaluate_direct.py`
- [x] Dedicated model path: `models/direct_agent.zip`

## Shared correctness and fair-comparison safeguards

- [x] Both styles use the same Arena physics, configuration, observations,
  reward hook, enemies, spawners, collisions, phases, and episode limits
- [x] `arena/controls.py` is the single source of truth for all action IDs
- [x] `make_rotation_env()` and `make_direct_env()` prevent accidental style
  overrides in training or evaluation code
- [x] Gym reset info exposes the selected style and ordered action meanings
- [x] Gym step info exposes the exact action index and name used
- [x] The normal HUD always displays the current action and full action map
- [x] `F3` debugger provides additional live movement evidence
- [x] Invalid or wrong-style actions are rejected
- [x] Shooting preserves momentum and never becomes an accidental brake
- [x] Holding movement plus Space in manual QA interleaves legal movement and
  shoot actions around the weapon cooldown
- [x] Exhaustive unit tests verify every ID, decoded command, axis direction,
  turn direction, action-space size, style lock, and shared observation shape
